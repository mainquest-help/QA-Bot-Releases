# QA 봇 툴 — 설치 파일

**받는 곳:** [Releases ▸ Latest](https://github.com/mainquest-help/QA-Bot-Releases/releases/latest) → **Assets** → `BlackHammer.QaBot-win-Setup.exe` 하나만 받아 더블클릭.

- «Windows의 PC 보호»가 뜨면 **추가 정보 → 실행** (사내 프로그램이라 서명이 없음).
- 설치 뒤에는 켤 때마다 새 판을 확인해 받아 두고, 닫으면 적용합니다(자동 업데이트).
- `Portable.zip` 은 자동 업데이트가 안 되니 받지 마세요. 나머지(`.nupkg` · `releases.win.json` 등)는 업데이트용 파일입니다.

## 처음 쓰기 — 세 번이면 끝

1. 설치한 «QA 봇 툴»을 켭니다.
2. **프로젝트 추가** → Unity 프로젝트 폴더 선택 → 서버 고르기(**개발 서버**) → 추가.
3. **시작** — QA 빌드 → 게임 여러 개 실행 → 봇 테스트 → 보고서까지 한 번에. 처음이면 «연습용 가짜 게임으로 체험»부터.

## 준비물

- Windows 10/11 64비트 · 메모리 16GB 이상
- Unity Hub(한 번 로그인) · git
- (안드로이드) 휴대폰 또는 앱플레이어 + adb

## 판 번호 · 바뀐 것

- 기능이 들어갈 때마다 새 판이 저절로 올라옵니다(`0.11.21` 처럼 끝자리가 올라감).
- 판마다 «바뀐 것»은 [Releases](https://github.com/mainquest-help/QA-Bot-Releases/releases) 각 판 설명에 있습니다.

이 저장소에는 완성된 설치 파일만 올라갑니다(툴 코드는 비공개 저장소). 사용법은 설치 폴더의 `사용설명서.html`(툴 «설정» 화면에서도 열림)을 보세요.
